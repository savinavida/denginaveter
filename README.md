# Деньги на ветер

Адаптивный калькулятор бюджета путешествий на чистых HTML, CSS и JavaScript. Сервер, база данных, сборка и платные API не нужны.

## Запуск локально

1. Скачайте и распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Измените количество путешественников, дни, ночи и суммы расходов.
4. Нажмите **«Рассчитать бюджет»**.

Все расходы вводятся общей суммой за поездку и за всех путешественников. Валюта — евро.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `app.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После публикации GitHub покажет адрес сайта в разделе Pages.

## Файлы проекта

- `index.html` — разметка и поля калькулятора.
- `styles.css` — адаптивный дизайн.
- `app.js` — проверки ввода, расчёты и диаграмма расходов.

## Формулы

- Общий бюджет = сумма всех пяти категорий.
- На человека = общий бюджет / число путешественников.
- За день = общий бюджет / число дней.
- Доля категории = расход категории / общий бюджет × 100%.

Денежные значения и доли показываются с точностью до двух знаков после запятой. При нулевом общем бюджете диаграмма остаётся нейтральной, а доли категорий равны нулю.
